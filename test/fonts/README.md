These unmodified DejaVu 2.37 fonts are test-only typography fixtures, loaded
explicitly by production-presentation tests. They are not runtime assets and do
not set the application's GTK or SQL font preferences. The ordinary application
continues to sample GTK interface fonts and use its existing monospace fallback.
